# 생각 거래소

생각을 올리고, 기존 생각에 경험·질문·제안을 보태고, 참여를 수락한 사람끼리 대화하는 웹 서비스입니다.

## 연결된 공간

- Firebase: `ideaexchange-e6646` / 개인 프로젝트
- Firestore: Standard, 서울(`asia-northeast3`), 기본 데이터베이스
- 요금제: Spark 무료. 결제 계정이나 유료 서비스는 연결하지 않습니다.
- 인증: Firebase 익명 인증 + 닉네임, 선택형 Google 계정 연결/로그인. 글은 로그인 없이 읽을 수 있습니다.
- 화면 배포: 개인 GitHub의 Pages. Firebase Hosting·Cloud Functions·파일 업로드는 사용하지 않습니다.

## 동작

- 글·보탬·관심은 Firestore에 공유 저장합니다. 예시 게시글을 실제 게시글처럼 넣지 않습니다.
- 새 글을 쓰면 작성자만 있는 대화방이 생깁니다. 다른 사람의 참여 신청을 글쓴이가 수락하면 해당 대화방에 들어갈 수 있습니다.
- 채팅과 가입 신청은 접근 규칙으로 보호합니다. 참여자가 아닌 사람이 주소나 요청을 바꿔도 읽을 수 없습니다.
- 첫 대화를 남기면 둘러보기와 원문에 대화 시작 여부, 작성자를 포함한 참여 인원, 최근 대화 시간이 표시됩니다. 대화 내용과 참여자 명단은 공개하지 않습니다. 인원과 시간은 실제 대화방·메시지와 대조하는 규칙으로 검증합니다.
- 기존 대화방은 참여자가 다시 접속할 때 실제 기록을 바탕으로 공개 활동 표시를 채웁니다. 참여 인원은 현재 접속자 수가 아니라 수락된 대화방 구성원 수입니다.
- 글은 20개, 보탬과 대화는 50개씩 불러옵니다. 이전 내용은 더 보기로 조회합니다.
- 활동 그래프는 실제 기록된 최근 최대 30개 관심·보탬을 사용합니다. 관심 1, 보탬 5로 반영하며 7일간 유지 후 8일째부터 하루 6%씩 낮아집니다. 관심 취소·재등록으로 같은 사람의 활동을 중복 적립하지 않습니다. 누적 글과 보탬은 삭제하지 않습니다.
- 닉네임만으로 참여하면 해당 브라우저에서 이어 씁니다. 이름 버튼 → Google 계정 연결을 선택하면 기존 UID를 보존해 원문·보탬·대화방·고정 권한을 유지합니다. 다른 기기는 시작하기 · 로그인 → Google로 로그인에서 같은 계정을 선택합니다. Google 실명과 이메일을 공개 프로필에 자동 복사하지 않습니다. 연결 전 브라우저 데이터를 지우면 기존 계정으로 돌아갈 수 없습니다.

## 실행과 배포

Node.js 22 이상을 사용합니다.

```sh
npm ci --ignore-scripts
npm run dev
npm test
npm run build
```

`main`에 반영하면 `.github/workflows/pages.yml`이 GitHub Pages에 배포합니다. Firebase 규칙을 바꿀 때는 검증 후 별도로 게시해야 합니다.

```sh
npm run test:rules
firebase deploy --only firestore:rules,firestore:indexes --project ideaexchange-e6646
```

규칙 테스트는 Java 21 이상과 Firebase Emulator를 사용하며 실제 프로젝트 대신 `demo-saenggak-exchange`에서 실행합니다. 실제 계정 정보는 필요하지 않습니다. 로컬 UI도 에뮬레이터에 연결하려면 Auth와 Firestore 에뮬레이터를 켜고 `VITE_FIREBASE_EMULATORS=true npm run dev`로 실행합니다. 이 옵션은 개발 모드에서만 적용됩니다.

`public/firebase-config.json`은 웹앱의 공개 연결 정보입니다. 관리자 비밀 키나 Google 로그인 토큰을 넣는 파일이 아닙니다. 서비스 계정 비밀 키·CLI 로그인 토큰은 저장소에 추가하지 마세요.

## 초기 운영 범위

둘러보기에는 고정 글 하나를 최신 글보다 먼저 표시합니다. 고정 글은 별도로 구독하므로 최신 20개 밖으로 밀려나도 유지됩니다. 운영자에게만 글 카드와 상세 화면에 `상단 고정`·`고정 해제` 버튼이 나타납니다. 다른 글을 고정하면 기존 고정을 대체합니다.

고정 권한은 Firebase 콘솔에서 `moderators/{실제 사용자 UID}` 문서의 `canPin: true`로 지정합니다. 닉네임으로 지정하지 않으며 클라이언트는 권한 문서를 만들거나 바꿀 수 없습니다. 공개 설정 `settings/community`는 `pinnedIdeaId`와 `updatedAt`만 저장합니다. 이 권한으로 비공개 대화 열람이나 타인의 글 변경은 할 수 없습니다. 운영자도 기존 익명 계정에 Google을 연결하면 UID와 고정 권한이 유지됩니다. 닉네임만 같은 다른 계정에는 권한이 생기지 않습니다.

소규모 초대 테스트를 위한 첫 버전입니다. 글 수정·삭제·신고, 운영자 관리 화면, 계정 병합·미연결 익명 계정 복구, 푸시 알림은 아직 없습니다. 글을 정리해야 할 때는 Firebase 콘솔에서 내용을 확인하고 처리합니다. 무료 한도가 찼다고 기존 이용자의 글을 자동으로 삭제하지 않습니다.

글과 보탬이 쌓인 뒤 비용이 걱정되면 Firebase 콘솔 사용량을 먼저 확인하세요. 저장 공간을 비우는 것과 이미 사용한 읽기·쓰기 한도를 되돌리는 것은 다릅니다.

## Google 로그인 운영

Firebase Authentication에서 Google 제공업체를 활성화하고 `taesooda-gif.github.io`를 승인된 도메인에 등록합니다. 팝업 방식은 GitHub Pages와 다른 Firebase 인증 도메인 사이의 리디렉션 저장소 제약을 피합니다. 팝업 차단 시 허용 후 다시 시도하며, 앱 내 브라우저에서는 Safari/Chrome을 안내합니다. 공개 OAuth 프로젝트 이름은 `생각 거래소`입니다.

기존 익명 계정에는 `linkWithPopup`, 미로그인 기기에는 `signInWithPopup`을 사용합니다. 이미 다른 계정에 연결된 Google을 골라도 자동 전환/병합하지 않습니다. 일반 이용자에게만 기록이 합쳐지지 않는다는 안내와 명시적 전환 확인을 제공하며 운영자 계정에는 전환을 노출하지 않습니다. Google 연결된 계정만 로그아웃할 수 있고, 계정 변경 때 비공개 대화/신청과 이전 계정의 화면 상태를 비웁니다.

인증과 저장소 에뮬레이터를 함께 켠 후 `node --test --test-concurrency=1 tests/rules.test.js tests/account.test.js`로 UID 보존, 기기 간 재로그인, 닉네임 유지, 권한과 개인 대화 접근, 연결 충돌을 검증합니다. 실제 Google 본인인증은 에뮬레이터가 대신 검증하지 않습니다.
