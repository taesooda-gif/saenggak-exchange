# 생각 거래소

생각을 올리고, 기존 생각에 경험·질문·제안을 보태고, 참여를 수락한 사람끼리 대화하는 웹 서비스입니다.

## 연결된 공간

- Firebase: `ideaexchange-e6646` / 개인 프로젝트
- Firestore: Standard, 서울(`asia-northeast3`), 기본 데이터베이스
- 요금제: Spark 무료. 결제 계정이나 유료 서비스는 연결하지 않습니다.
- 인증: Firebase 익명 인증 + 닉네임. 글은 로그인 없이 읽을 수 있습니다.
- 화면 배포: 개인 GitHub의 Pages. Firebase Hosting·Cloud Functions·파일 업로드는 사용하지 않습니다.

## 동작

- 글·보탬·관심은 Firestore에 공유 저장합니다. 예시 게시글을 실제 게시글처럼 넣지 않습니다.
- 새 글을 쓰면 작성자만 있는 대화방이 생깁니다. 다른 사람의 참여 신청을 글쓴이가 수락하면 해당 대화방에 들어갈 수 있습니다.
- 채팅과 가입 신청은 접근 규칙으로 보호합니다. 참여자가 아닌 사람이 주소나 요청을 바꿔도 읽을 수 없습니다.
- 첫 대화를 남기면 둘러보기와 원문에 대화 시작 여부, 작성자를 포함한 참여 인원, 최근 대화 시간이 표시됩니다. 대화 내용과 참여자 명단은 공개하지 않습니다. 인원과 시간은 실제 대화방·메시지와 대조하는 규칙으로 검증합니다.
- 기존 대화방은 참여자가 다시 접속할 때 실제 기록을 바탕으로 공개 활동 표시를 채웁니다. 참여 인원은 현재 접속자 수가 아니라 수락된 대화방 구성원 수입니다.
- 글은 20개, 보탬과 대화는 50개씩 불러옵니다. 이전 내용은 더 보기로 조회합니다.
- 활동 그래프는 실제 기록된 최근 최대 30개 관심·보탬을 사용합니다. 관심 1, 보탬 5로 반영하며 7일간 유지 후 8일째부터 하루 6%씩 낮아집니다. 관심 취소·재등록으로 같은 사람의 활동을 중복 적립하지 않습니다. 누적 글과 보탬은 삭제하지 않습니다.
- 닉네임 참여 기록은 해당 브라우저의 익명 계정에 연결됩니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 같은 작성자로 돌아갈 수 없습니다. 정식 계정 연결은 이후 개발 항목입니다.

## 실행과 배포

Node.js 22 이상을 사용합니다.

```sh
npm ci --ignore-scripts
npm run dev
npm test
npm run build
```

`main`에 반영하면 `.github/workflows/pages.yml`이 GitHub Pages에 배포합니다. Firebase 규칙을 바꿀 때는 검증 후 별도로 게시해야 합니다.

```sh
npm run test:rules
firebase deploy --only firestore:rules,firestore:indexes --project ideaexchange-e6646
```

규칙 테스트는 Java 21 이상과 Firebase Emulator를 사용하며 실제 프로젝트 대신 `demo-saenggak-exchange`에서 실행합니다. 실제 계정 정보는 필요하지 않습니다. 로컬 UI도 에뮬레이터에 연결하려면 Auth와 Firestore 에뮬레이터를 켜고 `VITE_FIREBASE_EMULATORS=true npm run dev`로 실행합니다. 이 옵션은 개발 모드에서만 적용됩니다.

`public/firebase-config.json`은 웹앱의 공개 연결 정보입니다. 관리자 비밀 키나 Google 로그인 토큰을 넣는 파일이 아닙니다. 서비스 계정 비밀 키·CLI 로그인 토큰은 저장소에 추가하지 마세요.

## 초기 운영 범위

소규모 초대 테스트를 위한 첫 버전입니다. 글 수정·삭제·신고, 운영자 관리 화면, 정식 계정 복구, 푸시 알림은 아직 없습니다. 글을 정리해야 할 때는 Firebase 콘솔에서 내용을 확인하고 처리합니다. 무료 한도가 찼다고 기존 이용자의 글을 자동으로 삭제하지 않습니다.

글과 보탬이 쌓인 뒤 비용이 걱정되면 Firebase 콘솔 사용량을 먼저 확인하세요. 저장 공간을 비우는 것과 이미 사용한 읽기·쓰기 한도를 되돌리는 것은 다릅니다.
